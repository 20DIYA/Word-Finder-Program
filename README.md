# 🔍 Word Finder Program (Go CLI)

**Word Finder Program** is a simple command-line tool written in Go. It allows you to search for words within a predefined string (`corpus`). When you run the program, you provide the words you want to search for, and it will output the index of the word found in the string.

This program demonstrates how to manipulate strings, use loops, and work with command-line arguments in Go.

---

## 🚀 How to Use

1. Clone this repository to your local machine.

2. Run the program from the command line, providing the word(s) you want to search for as arguments. For example:

```bash
go run main.go jumps again
